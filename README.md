# Свадебное приглашение · Александра и Михаил

## Файлы
- `index.html` — само приглашение (конверт, обращение, календарь, тайминг, ЗАГС, ресторан, дресс-код, подарки, организатор, анкета)
- `guests.js` — список гостей и их персональные обращения
- `img/` — картинки
- `rsvp-apps-script.gs` — скрипт, который складывает ответы анкеты в Google Таблицу

## Именные ссылки
Добавьте гостя в `guests.js`:

```js
ivanovy: { greet: "Дорогие Ольга и Игорь!", name: "Ольга и Игорь Ивановы", zags: false, to: "Ольги и Игоря" },
```

Ссылка для него: `https://<адрес-сайта>/?g=ivanovy`

- `zags: true` — ЗАГС + ресторан (с блоком ЗАГСа и пунктом 13:30 в тайминге)
- `zags: false` — сразу ресторан (блок ЗАГСа скрыт)
- `to` — надпись на конверте «Для …» (если не задано, падеж подбирается автоматически для простых имён)

Быстрый вариант без списка: `?name=Дорогой Пётр` (добавьте `&v=venue` для версии без ЗАГСа).
Пропустить конверт при проверке: `?g=alina&skip`.

## Анкета → Excel
1. Создайте пустую Google Таблицу.
2. Расширения → Apps Script → вставьте код из `rsvp-apps-script.gs` → Сохранить.
3. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение»; «Выполнять как: Я», «Доступ: Все» → разрешить доступ.
4. Скопируйте URL вида `https://script.google.com/macros/s/…/exec` и вставьте в `index.html`: `const RSVP_URL = '…';`
5. Ответы появляются в таблице сразу. Excel: Файл → Скачать → Microsoft Excel (.xlsx).
